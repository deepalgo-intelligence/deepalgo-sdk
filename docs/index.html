DeepAlgo Sovereign API

Base URL: api.deepalgo.co.uk API v4.1 pip install deepalgo-sovereign

Institutional AI regime classification, OU-calibrated entry signal quality, and order-flow intelligence across FX, metals, indices, and commodities. Three-lock validation stack: Regime Classification → Structural Noise Filter → Sequence Validation.

Authentication

All endpoints except GET /health and POST /register/free require an API key passed in the request header.

X-DeepAlgo-Key: your_api_key_here

Get a free key instantly — no card required:

curl -X POST https://api.deepalgo.co.uk/register/free \
  -H "Content-Type: application/json" \
  -d '{"email": "you@email.com"}'

Quick Start

pip install deepalgo-sovereign
from deepalgo_sovereign import DeepAlgoClient

# Register for a free key
DeepAlgoClient.enroll("you@email.com")

# Use your key
client = DeepAlgoClient(api_key="your_key_here")

regime = client.verify_regime("EUR_USD")
if regime["is_favorable"]:
    signal = client.get_entry_signal("EUR_USD")
    print(f"Entry quality: {signal['entry_quality']}")
    print(f"Wait {signal['recommended_delay_candles']} candles")

GET /regime/{asset}

GET /regime/{asset}

Returns the AI regime verdict for an instrument. Runs the full three-lock validation stack: Regime Classification (Lock 1) → Structural Noise Filter (Lock 2) → Sequence Validation (Lock 3).

Parameters

NameInTypeDescription
assetpathstringOANDA instrument name, e.g. EUR_USD, XAU_USD
use_tlockquerybooleanEnable Sequence Validation (Lock 3). Default: true

Example request

curl -s -H "X-DeepAlgo-Key: your_key_here" \
  "https://api.deepalgo.co.uk/regime/EUR_USD" | python3 -m json.tool

Example response

{
  "instrument": "EUR_USD",
  "is_favorable": false,
  "divergence": "NONE",
  "stability_score": "57.3%",
  "veto_reason": "REGIME_VETO",
  "metrics": {
    "regime": "TRENDING_RISK",
    "entropy": 0.547,
    "lock3_score": 0.77,
    "composite_confidence": 0.021
  }
}

Response fields

FieldTypeDescription
is_favorablebooleantrue if all active locks pass — safe to evaluate entry
veto_reasonstring | nullREGIME_VETO, TRANSFORMER_VETO, KS_BLOCK, or null if favorable
stability_scorestringComposite regime stability as a percentage
divergencestringCross-asset divergence signal: NONE, MILD, STRONG
metrics.regimestringMEAN_REVERTING, TRENDING_RISK, or NEUTRAL
metrics.entropyfloatShannon entropy of recent price action (0–1). Below 0.80 required to pass.
metrics.lock3_scorefloatSequence Validation model confidence (0–1)

GET /entry-signal/{instrument}

GET /entry-signal/{instrument} Professional+

Returns OU-calibrated entry timing quality. Derived from 60-day Information Coefficient analysis across 76 instruments — tells you not just whether the regime is right, but whether this specific moment is a statistically optimal entry point.

Example request

curl -s -H "X-DeepAlgo-Key: your_key_here" \
  "https://api.deepalgo.co.uk/entry-signal/GBP_USD" | python3 -m json.tool

Example response

{
  "instrument": "GBP_USD",
  "entry_quality": "MEDIUM",
  "current_ou_z": 0.663,
  "ou_z_threshold": 0.50,
  "recommended_delay_candles": 5,
  "best_confirmation_signal": "rsi",
  "calibrated": true
}

Response fields

FieldTypeDescription
entry_qualitystringHIGH (z ≥ 0.75), MEDIUM (z ≥ 0.50), LOW, or NO_DATA
current_ou_zfloatLive OU z-score — deviation from mean-reversion equilibrium in σ
ou_z_thresholdfloatCalibrated entry threshold from IC analysis for this instrument
recommended_delay_candlesintOptimal M5 candle wait after signal touch before entering
best_confirmation_signalstringHighest-IC confirmation signal at optimal lag: rsi, body_pct, rsi_divergence
calibratedbooleanfalse if instrument has insufficient calibration data

POST /v1/validate_sequence

POST /v1/validate_sequence

Runs the full three-lock validation stack using 60 M5 candles of OHLCV data you supply. Use this when you want to validate against your own data feed rather than OANDA.

Request body

{
  "asset": "EUR_USD",
  "candles": [
    {"time": "2026-05-31T10:00:00Z", "open": 1.0821, "high": 1.0835,
     "low": 1.0818, "close": 1.0829, "volume": 1200},
    ...  // 60 candles required
  ]
}

Example response

{
  "is_authorized": true,
  "verdict": "AUTHORIZED"
}

GET /health

GET /health No auth required

Returns API status, circuit breaker state, and per-lock health. Use this to monitor uptime or check the system before making regime calls.

Example request

curl -s https://api.deepalgo.co.uk/health | python3 -m json.tool

{
